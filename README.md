# ТАФС — библиотека схем (сайт-история)

Прототип v0.2.1 (16.10.2026). Схема «Опережающие сделки»: при прокрутке схема разворачивается на графике, в стакане и на счетах участников, затем ТАФС разбирает её за семь проверок и выставляет риск 0–100.

В v0.2 добавлены: скор риска (баллы за каждую проверку, зоны «низкий / средний / высокий»), режим воспроизведения (кнопка «Показать»: сцена прокручивает себя сама, любое касание останавливает), переключатель «Со схемой / Без схемы» во втором акте (контрфакт: банк набирает позицию в спокойном рынке по цене до схемы).

Готовый сайт — один файл `dist/index.html` (скрипты, стили и шрифты внутри, внешних CDN нет). Его можно открыть в браузере или залить на хостинг как есть.

## Сборка

```
npm install
npm run build
```

Нужен Node.js 18+. Результат: `dist/index.html` (сайт) и `dist/preview.html` (тот же контент без обёртки `<html>`, для превью).

## Библиотеки

| Что | Зачем |
|---|---|
| GSAP 3.15 + ScrollTrigger | закреплённые сцены, прокрутка = время схемы |
| GSAP SplitText | появление заголовка первого экрана |
| Lenis | плавная прокрутка (отключается при «меньше движения» в системе) |
| d3-scale, d3-array | шкалы, гистограмма, перцентиль, медиана |
| number-flow | перекатывающиеся цифры на счетах |
| Canvas 2D (свой код) | свечи, объёмы, разметка ТАФС, линза на первом экране |

Шрифт Inter (OFL, лицензия в `src/fonts`), только латиница, кириллица и знак ₽.

## Устройство

- `src/scenarios/front-running.json` — сценарий: параметры торгов (включая контрфакт `counterfactual`), подписи шагов, пункты протокола ТАФС с баллами `points`, зоны риска `score.bands`.
- `src/js/sim.js` — модель торгов по сценарию (детерминирована seed), контрфактный ряд `cf` и все метрики: проскальзывание, перцентиль, оборот, потеря банка.
- `src/js/acts.js` — кадры двух актов как функции от шага и прогресса прокрутки (назад отматывается без накопленного состояния).
- `src/js/chart.js` — рендер графика, гистограммы и шкалы времени заявок.
- `src/js/ui.js` — стакан, счета участников, протокол ТАФС.
- `src/js/stage.js` — закреплённая сцена, подписи, полоски шагов, режим воспроизведения.
- `src/js/hero.js` — первый экран с «линзой ТАФС».
- `src/styles.css`, `src/index.html` — вёрстка.

## Новая схема

1. Новый файл в `src/scenarios/` с параметрами и подписями.
2. Модель торгов для неё в `sim.js` (у каждой схемы своя механика).
3. Кадры актов в `acts.js`. График, стакан, счета и протокол переиспользуются.

Все цены и объёмы смоделированы, на странице об этом есть пометка.

## Версии и откат

- Ветка `main` — то, что показывается заказчику. Каждая принятая версия помечена тегом вида `v0.2.1`; список тегов — на странице репозитория в разделе Tags (Releases).
- Изменения делаются в отдельной ветке и приходят в `main` через pull request, чтобы их можно было посмотреть до слияния и при необходимости отменить одним действием (Revert на странице PR).
- Вернуться к любой принятой версии: `git checkout v0.2.1 -- src build.mjs package.json` и новый коммит, либо Revert соответствующих PR на GitHub. Собранный сайт этой версии лежит в `dist/index.html` того же тега.
- `dist/index.html` коммитится вместе с исходниками: он и есть поставляемый файл, его можно скачать с GitHub без сборки.
