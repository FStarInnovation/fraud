# ТАФС — библиотека схем (сайт-история)

Прототип v0.3 (20.10.2026). Одна страница: первый экран, библиотека, затем схемы по порядку — у каждой вступление с ключевыми цифрами, акт I (схема разворачивается на графике, в стакане и на счетах участников) и акт II (ТАФС разбирает её по проверкам и выставляет риск 0–100), в конце общий призыв к демонстрации.

- Схема 1 «Опережающие сделки» — 8 шагов, 7 проверок, риск 91.
- Схема 2 «Занижение цены перед крупной сделкой» — 9 шагов, 9 проверок, риск 94: три торговые недели по часовым свечам, отраслевой индекс, карта ликвидности (цена по времени, блоки заявок у лучшей цены, растущий спред), встречные заявки, крупная сделка вне основных торгов, граф связей участников, блок «Вывод ТАФС».

В v0.2 добавлены: скор риска (баллы за каждую проверку, зоны «низкий / средний / высокий»), режим воспроизведения (кнопка «Показать»: сцена прокручивает себя сама, любое касание останавливает), переключатель «Со схемой / Без схемы» во втором акте (контрфакт: банк набирает позицию в спокойном рынке по цене до схемы).

Готовый сайт — один файл `dist/index.html` (скрипты, стили и шрифты внутри, внешних CDN нет). Его можно открыть в браузере или залить на хостинг как есть.

## Сборка

```
npm install
npm run build
```

Нужен Node.js 18+. Результат: `dist/index.html` и `dist/preview.html` (тот же контент без обёртки `<html>`, для превью-артефакта; в репозиторий не входит).

## Библиотеки

| Что | Зачем |
|---|---|
| GSAP 3.15 + ScrollTrigger | закреплённые сцены, прокрутка = время схемы |
| GSAP SplitText | появление заголовка первого экрана |
| Lenis | плавная прокрутка (отключается при «меньше движения» в системе) |
| d3-scale, d3-array | шкалы, гистограмма, перцентиль, медиана |
| number-flow | перекатывающиеся цифры на счетах |
| Canvas 2D (свой код) | свечи, объёмы, разметка ТАФС, линза на первом экране |

Шрифт Inter (OFL, лицензия в `src/fonts`), только латиница, кириллица и знак ₽.

## Устройство

Общее для всех схем:

- `src/js/chart.js` — рендер на Canvas 2D: свечи и объёмы (сегменты по участникам задаёт страница через `opts.volumes`), подписи оси времени (`opts.xTicks`), линия индекса, разметка (`hline`, `vline`, `dimV`, `bracket`, `chevrons`, `ring`, `band`, `inset`, `block`, `dot`) и режимы: гистограмма сделок (`hist`), шкала времени заявок (`timeline`), карта ликвидности (`heat`), распределение (`dist`), граф связей (`graph`).
- `src/js/ui.js` — стакан, карточки участников (`createAccounts` для схемы 1, `createParties` для произвольных сторон), протокол ТАФС со скором.
- `src/js/stage.js` — закреплённая сцена, подписи, полоски шагов, режим воспроизведения.
- `src/js/palette.js`, `src/js/fmt.js` — цвета разметки из CSS-переменных, русское форматирование чисел.
- `src/js/main.js` — страница целиком: плавная прокрутка, первый экран, якоря и кнопки «Смотреть схему», подключение схем по порядку, итог. Каждая схема — модуль `scheme-*.js` с функцией `init(root, …)`, которая оживляет свой блок `<div class="scheme">` в `src/index.html`.
- `src/styles.css`, `src/index.html` — вёрстка.

Схема 1 («Опережающие сделки», блок `#fr`, `src/js/scheme-front-running.js`):

- `src/scenarios/front-running.json` — сценарий: параметры торгов (включая контрфакт `counterfactual`), подписи шагов, пункты протокола с баллами `points`, зоны риска `score.bands`.
- `src/js/sim.js` — модель торгов (детерминирована seed), контрфактный ряд `cf` и метрики.
- `src/js/acts.js` — кадры двух актов как функции от шага и прогресса прокрутки (назад отматывается без накопленного состояния).
- `src/js/hero.js` — первый экран с «линзой ТАФС».

Схема 2 («Занижение цены перед крупной сделкой», блок `#sq`, `src/js/scheme-suppression.js`):

- `src/scenarios/suppression.json` — параметры (15 дней по 9 часовых свечей, позиция 10 млн, продажи 2 млн за неделю с долей 64 % оборота, снижение до 91, индекс с весом бумаги 10 %, спред и глубина, крупная сделка 8 млн по 89, восстановление до 95), стороны `parties`, шаги и проверки.
- `src/js/sim-suppression.js` — модель: спокойная неделя идёт с рынком и заканчивается ровно на 100, неделя продаж с агрессивной долей 88 % и встречными заявками 65 %, восстановление рывками, ликвидность по барам, история пятидневных отклонений от индекса, метрики (712 млн, 800 млн, 88 млн, ×36 к дневному обороту, 5σ). `bookAt` строит стакан на момент t.
- `src/js/acts-suppression.js` — кадры актов, данные карты ликвидности, распределения и графа связей.

## Новая схема

1. Новый файл в `src/scenarios/` с параметрами и подписями.
2. Модель торгов для неё (у каждой схемы своя механика) и кадры актов — по образцу `sim-suppression.js` и `acts-suppression.js`.
3. Блок `<div class="scheme" id="…">` в `src/index.html` (вступление, акт I, глава, акт II) с уникальными id секций, модуль `src/js/scheme-<схема>.js`, строка в списке `schemes` в `main.js`, чип в библиотеке. График, стакан, карточки и протокол переиспользуются.

Все цены и объёмы смоделированы, на странице об этом есть пометка.

## Версии и откат

- Ветка `main` — то, что показывается заказчику. Каждая принятая версия помечена тегом вида `v0.2.1`; список тегов — на странице репозитория в разделе Tags (Releases).
- Изменения делаются в отдельной ветке и приходят в `main` через pull request, чтобы их можно было посмотреть до слияния и при необходимости отменить одним действием (Revert на странице PR).
- Вернуться к любой принятой версии: `git checkout v0.2.1 -- src build.mjs package.json` и новый коммит, либо Revert соответствующих PR на GitHub. Собранный сайт этой версии лежит в `dist/index.html` того же тега.
- `dist/index.html` коммитится вместе с исходниками: он и есть поставляемый файл, его можно скачать с GitHub без сборки.
